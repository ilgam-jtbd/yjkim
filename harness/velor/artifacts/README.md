# velor 하네스 산출물 지도

velor 하네스의 모든 중간/최종 결과가 모이는 곳입니다. 다음 실행이 무엇을 읽어야 하는지 알려주는 지도입니다.

## 파일 규칙
| 종류 | 경로 예 | 만드는 역할 |
| --- | --- | --- |
| 그로스 실험 | `{날짜}-growth-{실험명}.md` | velor-growth-experiment |
| 매칭/리크루팅 | `{날짜}-matching-{수요처}.md` | velor-matching-recruiter |
| IR/투자 | `{날짜}-ir-{라운드}.md` | velor-ir-advisor |
| 콘텐츠/마케팅 | `{날짜}-content-{캠페인}.md` | velor-content-marketer |
| 협업 통합 | `{날짜}-final-{주제}.md` | velor-orchestrator |
| 개선 기록 | `improvement-log.md` | 누구나(피드백 반영 시) |

날짜는 `YYYY-MM-DD` 형식.

## 사람 승인 표시
외부 발송·광고 집행·게시·결제·DB 변경·IR 제출이 포함된 산출물에는 문서 상단에
`승인 필요: [ ] (담당/일시)` 체크 줄을 둡니다. 승인 전에는 실행하지 않습니다.

## 재실행 시
부분 재실행("이 부분만 다시", "이전 결과 기반 보완")은 기존 산출물을 읽고 변경분만 갱신한 뒤,
무엇을 왜 바꿨는지 `improvement-log.md`에 한 줄 남깁니다.
